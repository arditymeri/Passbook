# Spec: Add Income

**Sprint:** 1  
**Status:** Implemented  

---

## Goal

Allow a user to record an income entry in the system so that their financial inflows are tracked alongside expenses.

---

## User Story

> As a user, I want to add an income entry with an amount, date, and source, so that I can track where my money comes from.

---

## Acceptance Criteria

### Happy path
- **Given** a valid request with `amount > 0` and `time` set  
  **When** `POST /api/v1/incomes` is called  
  **Then** the response is `201 Created` with the saved income including a generated `id`

### Validation — amount
- **Given** a request with no `amount`  
  **When** `POST /api/v1/incomes` is called  
  **Then** the response is `400 Bad Request`

- **Given** a request with `amount = 0` or `amount < 0`  
  **When** `POST /api/v1/incomes` is called  
  **Then** the response is `400 Bad Request`

### Validation — time
- **Given** a request with no `time`  
  **When** `POST /api/v1/incomes` is called  
  **Then** the response is `400 Bad Request`

### Retrieval
- **Given** an income has been created  
  **When** `GET /api/v1/incomes/{id}` is called with its id  
  **Then** the response is `200 OK` with the income

- **When** `GET /api/v1/incomes` is called  
  **Then** the response is `200 OK` with a list of all incomes

---

## API Contract

### POST /api/v1/incomes

**Request body** (`createIncomeRequest`):

| Field               | Type     | Required | Notes                                          |
|---------------------|----------|----------|------------------------------------------------|
| `amount`            | double   | ✅       | Must be > 0                                    |
| `time`              | datetime | ✅       | ISO 8601 with offset                           |
| `description`       | string   | —        |                                                |
| `currency`          | string   | —        |                                                |
| `source`            | enum     | —        | SALARY, FREELANCE, INVESTMENT, RENTAL, GIFT, OTHER |
| `payer`             | string   | —        |                                                |
| `accountId`         | string   | —        |                                                |
| `notes`             | string   | —        |                                                |
| `recurring`         | boolean  | —        |                                                |
| `recurringFrequency`| enum     | —        | DAILY, WEEKLY, MONTHLY, YEARLY                 |

**Responses:**
- `201 Created` — income saved, returns `incomeResponse` with `id`
- `400 Bad Request` — validation failed

### GET /api/v1/incomes

**Responses:**
- `200 OK` — returns `incomeListResponse`

### GET /api/v1/incomes/{id}

**Responses:**
- `200 OK` — returns `incomeResponse`
- `404 Not Found` — no income with that id

---

## Domain Rules

1. `amount` is required and must be greater than zero — enforced in `AddIncomeServiceImpl`
2. `time` is required — enforced in `AddIncomeServiceImpl`
3. All other fields are optional
4. The `id` is generated by the database (UUID)
