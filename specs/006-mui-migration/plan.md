# Implementation Plan: Material UI Migration

**Branch**: `006-mui-migration` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/006-mui-migration/spec.md`

## Summary

Migrate the existing React 18 + TypeScript frontend from raw HTML / hand-written CSS to MUI v5 (`@mui/material`). Replace all 10 components and 2 CSS files with MUI equivalents, keeping all TypeScript prop interfaces unchanged. No backend, routing, or data-logic changes. All existing CRUD operations remain functional. Currency amount fields use `type="text"` with string state to comply with Constitution Principle IV.

## Technical Context

**Language/Version**: TypeScript 4.6, React 18.2, Node.js (Vite 3.1 bundler)

**Primary Dependencies (current)**: React 18, React DOM 18, Vite 3, TypeScript

**Primary Dependencies (adding)**: `@mui/material ^5`, `@emotion/react`, `@emotion/styled`, `@mui/icons-material`

**Storage**: N/A — frontend only

**Testing**: TypeScript type-check (`tsc --noEmit`) + manual browser smoke-test per user story

**Target Platform**: Web browser, desktop-primary (Chrome/Firefox/Safari on macOS/Windows)

**Performance Goals**: Dashboard initial load < 3 s; MUI v5 tree-shaken by Vite — bundle increase < 150 kB gzip

**Constraints**:
- Pure visual layer change — zero API, routing, or business-logic changes
- `amount` form fields MUST use `type="text"` with string state (Constitution Principle IV — no floating-point money)
- All existing prop interfaces remain unchanged
- No new features introduced

**Scale/Scope**: 10 components, 2 CSS files, 1 new theme file, 1 root component update

## Implementation Notes

### Installation
```bash
cd frontend
npm install @mui/material @emotion/react @emotion/styled @mui/icons-material
```

### Theme (theme.ts)
```ts
import { createTheme } from '@mui/material/styles';
export const theme = createTheme({
  palette: {
    primary: { main: '#1a1a2e' },
    secondary: { main: '#3f8efc' },
    background: { default: '#f5f7fa' },
  },
  shape: { borderRadius: 8 },
});
```

### App.tsx shell
```tsx
import { ThemeProvider, CssBaseline } from '@mui/material';
import { theme } from './theme';

// Wrap entire return with:
<ThemeProvider theme={theme}>
  <CssBaseline />
  {/* existing tree */}
</ThemeProvider>
```

### Amount field pattern (all forms)
```tsx
// CORRECT — string state, no floating point in UI layer
const [amount, setAmount] = useState('');
<TextField
  type="text"
  label="Amount (EUR)"
  value={amount}
  onChange={(e) => setAmount(e.target.value)}
  inputProps={{ inputMode: 'decimal', pattern: '[0-9]*\\.?[0-9]*' }}
/>
// At API boundary only:
amount: parseFloat(amount)
```
